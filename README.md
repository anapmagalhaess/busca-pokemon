# Projeto PokéAPI - Java & Gson

Aplicação desenvolvida em Java utilizando o Maven, projetada para consumir a PokéAPI e exibir informações detalhadas de Pokémon através de uma interface gráfica interativa (`JOptionPane`).

## 🚀 Tecnologias Utilizadas

- **Java 21**
- **Maven** (Gerenciamento de dependências)
- **HttpClient** (Requisições HTTP nativas)
- **Google Gson** (Desserialização de JSON)
- **Java Swing** (Interface Gráfica)

## 📋 Funcionalidades

- Consulta de Pokémon por nome ou número de identificação.
- Exibição de dados formatados: ID, Nome, Tipo(s) e a Sprite frontal oficial do Pokémon.
- Tratamento de exceções e validações de entrada do utilizador e de status de conexão da API.

## 🛠️ Como Executar

1. Certifica-te de que tens o **Java 21** e o **Maven** instalados.
2. Clona este repositório para a tua máquina.
3. Importa o projeto na tua IDE de preferência (IntelliJ IDEA, Eclipse, etc.) como um **Projeto Maven**.
4. Executa a classe principal `PokemonApp.java`.
